# واصل — مراسلة عربية

واجهة مراسلة عربية متجاوبة مع Supabase.

## الروابط

- الموقع: افتح `index.html`
- لوحة الإدارة: افتح `admin.html` وسجّل الدخول بحساب أدمن

## ملاحظات

لوحة الإدارة تستخدم دوال Supabase محمية بصلاحية `admin` لإدارة المستخدمين، وتدعم تعديل البيانات، تغيير الدور، تعليق الحساب أو حذفه.
